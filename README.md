# Invitations personnalisées — Chadrack & Dina

Chaque fichier HTML est une invitation personnalisée pour un invité et sa table.

## Utilisation sur GitHub Pages
1. Téléverser tous les fichiers HTML dans le dépôt GitHub.
2. Activer GitHub Pages sur la branche contenant ces fichiers.
3. Chaque fichier peut ensuite être ouvert directement avec son URL GitHub Pages.

Le QR code intégré à chaque invitation contient le nom de l'invité et sa table.
